# InfraPilot AI Demo Script

## 0–8 seconds — HOOK

"AI can write an application in minutes. But can it understand how that application should actually run in production?"

- Show the InfraPilot landing page.
- Highlight the repo input and the big Analyze button.

## 8–18 seconds — PROBLEM

"InfraPilot acts like an AI Forward Deployment Engineer. Give it an unfamiliar repository and it reconstructs the deployment architecture."

- Paste the GitHub repository URL into the dashboard.
- Start analysis.

## 18–35 seconds — DISCOVERY

Show:

- files analyzed summary or progress
- stack signals discovered
- services discovered
- architecture graph

Narration:

"InfraPilot analyzes dependency manifests, source entrypoints, Docker configuration, environment contracts, and service boundaries instead of blindly prompting an LLM."

## 35–48 seconds — ZEROPS PLAN

Show:

- readiness score
- infrastructure plan sections
- environment mapping
- generated zerops.yaml

Narration:

"It translates those findings into an explainable Zerops infrastructure plan." 

## 48–65 seconds — FAILURE

Show a real deployment error or paste a failure log into Deployment Doctor.

Narration:

"When deployment fails, InfraPilot correlates logs with repository evidence."

Show:

- ROOT CAUSE
- EVIDENCE
- FIX

## 65–78 seconds — VERIFY

Show health/readiness/evidence UI.

Narration:

"InfraPilot doesn't call deployment successful just because the build passed. It looks for evidence that the application is actually working." 

## 78–90 seconds — CLOSING

Show the live URL and architecture.

Narration:

"InfraPilot AI — from repository to verified production, built on Zerops."
